🍎 봉우리 발주 취합 및 정돈 시스템 (Web Ver.)

Streamlit 기반의 엑셀 데이터 대량 취합 및 송장 정돈 웹 애플리케이션입니다.

다양한 거래처의 발주서 양식을 자동으로 통합하고, 상품명 사전 연동, 송장 검수, 수량별 행 분리 등의 업무 automated 솔루션을 제공합니다.

📌 주요 기능 (Features)

1. 📦 대량 취합 실행 (tab1)

다중 엑셀 병합: 여러 거래처의 엑셀 파일(.xlsx, .xls)을 드래그 앤 드롭으로 업로드하여 하나로 병합.

순서 변경 및 삭제: drag/drop 업로드 후 🔼, 🔽, ❌ 버튼으로 취합 순서 및 대상 관리.

자동 상품명 변환: 구글 시트 사전 데이터 기반으로 거래처별 상품명을 통일된 상품명으로 자동 매핑.

미등록 상품 처리: 구글 시트에 없는 상품은 셀 색상(오렌지색)으로 강조 표시 및 목록 제공.

취합 결과 검수: 유효 데이터 건수, 실패 원인(업체 미선택, 형식 오류 등) 상세 안내.

2. ⚙️ 거래처 양식 관리 (tab2)

거래처별 매핑 설정: 각 업체 발주서의 시작 행 및 컬럼(A, B, C...) 매핑 등록 및 수정.

설정 백업: web_settings.json 백업 다운로드 기능 지원.

3. 🚚 송장 정돈 및 검수 (tab3)

컬럼 자동 정돈: 송장 원본에서 주요 컬럼(운송장번호, 수하인명, 상품명, 연계비용 등)만 정렬 및 추출.

연계비용 초과 강조: 연계비용 170원 초과 건 강조 표시(노란색 셀 지정).

서식 보존: 운송장번호/주문번호 텍스트 서식 유지 및 자동 필터 부착.

4. 🔢 수량별 행 분리 (tab4)

서식 보존 행 분리: 수량이 2 이상인 주문을 1개당 1행으로 분리.

스타일 유지: openpyxl을 활용하여 폰트, 테두리, 배경색, 행 높이 등의 원본 서식을 손상 없이 복사.

5. 🛠️ 최종 출력 양식 관리 (tab5)

출력 엑셀 컬럼 커스텀: 결과물 엑셀의 열 위치(A~P 등) 변경 및 고정값(보내는 주소 등) 관리.

6. 🔗 구글 시트 연동 (tab6)

실시간 사전 매핑: 웹에 게시된 구글 시트 CSV URL을 등록하여 [원본 상품명 ➡️ 변환 상품명] 규칙을 갱신.
